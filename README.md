# 🎬 Flow 콘티 스튜디오 v2

AI 영상(Flow 등) 제작용 **기획 → 콘티 → 제작 → 마무리** 4단계 작업 도구입니다.
서버·API 키 없음. 모든 데이터는 **내 브라우저**에만 자동 저장됩니다.

- 🌐 주소: https://kaycomm21.github.io/flow-studio/
- 화면 맨 위 **▶ 다음 할 일** 막대만 따라 누르면 한 편이 끝납니다.

## ✅ 사용법
| 단계 | 하는 일 |
|---|---|
| ① 기획 | 주제·핵심 사실 입력 → 프리셋 선택 → **[요청문 복사] → 내 Claude/Gemini에 붙여넣기 → 답변 붙여넣고 [콘티에 적용]** |
| ② 콘티 | 샷 카드를 눌러 수정. 경고가 뜨면 **[🔧 자동 수정]**. 모델 배분(절약/균형/최고)으로 예상 크레딧 조절 |
| ③ 제작 | 참조 이미지(캐릭터·장소 시트) 먼저 → 샷마다 **[복사] → Flow에서 생성 → [＋생성 1회 기록] → 채택/재생성/폐기**. 재생성 때 문제를 고르면 보정 지시가 프롬프트에 자동으로 붙습니다 |
| ④ 마무리 | 나레이션 대본·자막(SRT)·편집 큐시트(CSV)·오디오 큐시트 내려받기, 크레딧 지갑, 백업 |

- 📁 **보관함**(오른쪽 위 편 이름): 여러 편 관리, **[다음 편]** 은 스타일·캐릭터·장소를 그대로 가져옵니다.
- 💳 **크레딧**: 모든 편 합산 잔량. 모델별 1회 비용 기본값은 **추정치**이니 마무리 탭에서 Flow의 실제 차감값으로 고치세요.
- 🌐 피사체·동작 등 프롬프트 칸에 한글이 있으면 기획 탭에 **영어 변환 도우미**가 나타납니다. 나레이션은 한국어 그대로 씁니다.
- ⚠️ 실존 인물·정당 이름은 목록 기반으로만 경고합니다. 목록에 없는 이름은 직접 확인하세요.
- 🗄 PC·태블릿을 오갈 때: 마무리 탭 **[전체 백업]** 파일을 옮겨 **[JSON 불러오기]**.

## 💻 로컬 실행 (Node.js LTS 필요)
```bash
git clone https://github.com/kaycomm21/flow-studio.git
```
```bash
cd flow-studio
```
```bash
npm install
```
```bash
npm run dev
```
→ http://localhost:5173 접속. 테스트는 `npm test`, 빌드는 `npm run build`(결과물 `dist/`).

개발·유지보수 정보는 `HANDOFF.md`를 보세요.
